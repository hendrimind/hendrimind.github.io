Admin Credentials

Info: Untuk mengganti username & password admin, ikuti langkah berikut di Vercel Dashboard.
Langkah-langkah:
  1. Buka Vercel Dashboard → Settings → Environment Variables
  2. Cari variable ADMIN_USERNAME → klik edit → ganti nilainya
  3. Cari variable ADMIN_PASSWORD → klik edit → ganti nilainya
  4. Klik Save
  5. Klik Redeploy di halaman Deployments
  6. Login ulang di halaman ini dengan credentials baru
Peringatan:
  • Jangan lupa Redeploy setelah mengubah env variables
  • Perubahan berlaku setelah server restart
  • Ganti JWT_SECRET juga untuk keamanan ekstra
